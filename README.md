# Bank Management System

A desktop-based Bank Management System developed using Java Swing and MySQL.  
This project simulates basic banking operations with a user-friendly graphical interface.

## Features

- User Login Authentication
- Account Registration / Signup
- Deposit Money
- Withdraw Money
- Fast Cash Service
- Balance Enquiry
- PIN Change
- Interactive GUI using Java Swing
- Database Connectivity using JDBC

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- IntelliJ IDEA

## Project Purpose

This project was developed to improve understanding of:

- Object-Oriented Programming (OOP)
- Java GUI Development
- Database Connectivity
- Event-Driven Programming
- Real-World Banking Workflow
